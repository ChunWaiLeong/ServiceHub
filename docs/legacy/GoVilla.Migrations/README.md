# Archived GoVilla migration history

These three files preserve the original EF Core migration history during the ServiceHub foundation transition. They reference the retired GoVilla model and assemblies and are intentionally outside the active solution.

Do not execute them against ServiceHub. No new migration or domain model exists in Phase 1. Decide the database transition during the persistence phase, after confirming whether existing data needs to be retained.
